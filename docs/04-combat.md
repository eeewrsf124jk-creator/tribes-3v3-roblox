# 04. 전투

관련 코드: `LagCompensatedCombatService.luau`, `Combat/DamageModel.luau`, `Combat/ProjectileSimulator.luau`, `Combat/CombatantRegistry.luau`, `Combat/UtilityAndHealing.luau`, 클라이언트 `WeaponAndProjectileController.luau`, `ProjectileRenderer.luau`, `MovementController.luau`. 상수는 `GameConfig.Combat`, `GameConfig.Movement`에 있습니다.

## 기본 원칙

- **서버가 판정합니다.** 클라이언트는 "이 방향으로 쐈다", "휘둘렀다"만 보내고, 맞았는지와 대미지는 서버가 정합니다.
- **반응은 즉시 보입니다.** 내가 쏜 화살은 버튼을 놓는 순간 내 화면에 먼저 날아가고, 서버 결과가 오면 그 위치에서 사라집니다.
- **대미지는 한 곳에서만 계산합니다.** 모든 피해(무기, 덫, 화염, 링)가 `DamageModel.Apply`를 지납니다.

체력은 100입니다(`MaxHealth`). 같은 팀은 서로 피해를 주지 않습니다.

## 대미지 계산 순서 (`DamageModel.Apply`)

1. **막기 / 방패** (공격이 정면에서 올 때만: 피해자 시선과 공격 방향의 내적 < −0.4)
   - 방패를 든 상태
     - 화살·총알: **완전히 막고** 화살은 방패에 꽂힙니다.
     - 근접: 대미지가 방패 내구도(기본 120)에서 빠집니다. 0이 되면 방패가 깨지고 막기가 풀립니다.
   - 검으로 막는 상태 (`CanBlock` 무기): 근접 대미지를 무기의 `BlockDamageReduction`만큼 줄입니다(철검 80%, 카타나 70%).
2. **방어구**
   - 먼저 감쇄: 원거리·전술 도구 피해는 `RangedDmgReduction`(가죽 15% / 철 30% / 다이아 40%), 근접 피해는 `MeleeDmgReduction`(다이아 15%)만큼 줄입니다.
   - 그다음 방어구 내구도(`ArmorHP`)가 먼저 받아내고, 남은 만큼만 체력이 깎입니다.
   - 전투 도끼 같은 방어구 파쇄(`ArmorShredRatio`)는 방어구에 들어가는 대미지를 그만큼 키웁니다.
   - 내구도가 0이 되면 모두에게 **ARMOR BROKEN**을 알리고 캐릭터의 갑옷 모델을 없앱니다.
3. **체력**: 남은 대미지를 체력에서 뺍니다. 사격장 허수아비는 죽지 않고 받은 대미지만 표시합니다.
4. **경직** (`Stagger`, 막히지 않았을 때): 해머는 0.8초 동안 **STAGGERED**. 그동안 이동 속도가 절반이 되고 회복이 끊기며 사격·충전이 취소됩니다.
5. **넉백**: 공격 방향으로 수평 충격 + 위로 18. 다이아 갑옷은 넉백 50% 저항, 막았을 때는 35%만 받습니다.
6. **처치와 도움**: 체력이 0이 되면 처치. 최근 8초(`AssistWindow`) 안에 피해를 준 다른 아군은 도움으로 기록됩니다.

## 특수 판정

| 판정 | 규칙 |
|---|---|
| 헤드샷 | `Head` 파트에 맞으면 무기의 `HeadMult`를 곱합니다(예: 나무 활 1.75, 석궁 1.75, 헤드헌터 2.0) |
| 백스탭 | 다이아몬드 단검으로 공격할 때 공격자와 피해자가 같은 방향을 보고 있으면(시선 내적 > 0.5, 등 뒤 약 120도) **250 대미지 즉사**. 막기와 방어구를 무시합니다 |
| 해머 | 넉백 65, 경직 0.8초 |
| 전투 도끼 | 길게 눌러 내려찍기(58 대미지) + 방어구 파쇄 50% |
| 블런더버스 | 펠릿 8개 × 14. 18 스터드부터 27 스터드에 걸쳐 35%까지 약해집니다 |
| 불화살 | 맞으면 3초 동안 초당 6 화상 대미지 |
| 슬라이드 | 슬라이드 중에는 히트박스가 55%로 작아집니다 |
| 업그레이드 | 장비 레벨 L의 대미지·회복량·내구도는 `1.04^(L−1)`배 (Lv10 = 1.423배) |

## 원거리: 랙 보정

1. 클라이언트가 `FireProjectile`에 {슬롯, 발사 위치(머리), 방향, 당김 비율, 클라이언트 시간, 시드, 불화살 여부}를 보냅니다.
2. 서버 검사: 발사 위치가 서버가 아는 머리 위치에서 7 스터드(`ORIGIN_TOLERANCE`) 안인지, 쿨다운·장전·탄약이 맞는지, 숫자가 유한한지.
3. **되감기**: 서버는 모든 캐릭터의 부위별 위치를 20Hz로 1초 동안 기록합니다(`CombatantRegistry`). 투사체가 날아가는 동안 각 구간을 "그 시점 − 쏜 사람의 지연 시간"의 히트박스와 비교합니다. 지연 보정은 최대 0.4초(`MaxRewindLatency`), 판정 여유는 0.6 스터드(`HitboxTolerance`)입니다.
4. **따라잡기**: 패킷이 늦게 도착한 만큼 투사체를 앞으로 진행시킨 뒤 시작합니다.
5. 비행은 1/60초 단위로 포물선 P(t) = P0 + V0·t + ½·g·t²을 따르고, 맵은 Projectiles 충돌 그룹으로 레이캐스트합니다. 최대 4초 동안 날아갑니다.
6. 결과는 `ProjectileReplicate`(다른 사람 화면에 그리기)와 `ProjectileResolved`(맞은 위치)로 보냅니다. 벽이나 방패에 박힌 화살은 최대 60개까지 남습니다.

특수 투사체:

- **차크람**: 벽에 맞으면 R = V − 2(V·N)N으로 반사, 2번 튕긴 뒤 던진 사람에게 돌아옵니다. F로 잡으면 다시 던질 수 있습니다.
- **블런더버스**: 서버와 모든 클라이언트가 같은 시드로 같은 펠릿 방향을 만들어 화면과 판정이 일치합니다.
- **작살**: 맞은 상대를 끌어당깁니다(`PullForce` 85).
- **볼라**: 2.5초 동안 이동 속도 25%.

## 근접

- 클라이언트가 `MeleeSwing`을 보내면, 서버가 되감은 히트박스로 110도 원호(`MeleeArcDegrees`)와 무기 사거리(+1.75 스터드 여유) 안의 적을 찾습니다.
- 무기마다 `SwingRate`(휘두르기 간격), `Range`가 다릅니다([reference/equipment.md](reference/equipment.md)).
- 우클릭을 누르고 있으면 막기(`ToggleBlock`). 방패는 우클릭이나 좌클릭으로 듭니다.

## 전술 도구와 회복

| 아이템 | 동작 |
|---|---|
| 연막탄 | 던지면 반경 16 스터드, 8초 연막 |
| 곰 덫 | 14 스터드 안에 설치. 밟으면 35 대미지 + 2.5초 속박 |
| 나무 성벽 | 14 스터드 안에 설치. 내구도 180, 25초 유지. 투사체를 막고 부술 수 있음 |
| 뿔피리 | 쿨다운 20초. 적 위치를 5초 동안 아군에게 보여주고(빨간 윤곽선), 아군 이동 속도 1.2배 |
| 화염구 | 던지면 35 대미지 + 반경 10 불길, 4초 동안 초당 8 |
| 붕대 | 2.2초 시전, 35 회복. 시전 중 느리게 이동 가능 |
| 사과 | 1.2초 시전, 50 회복 |
| 회복 플라스크 | 던지면 반경 8 안의 아군 모두 60 회복 |
| 황금 사과 | 즉시 먹고 3초 동안 100 회복 |

- 설치형(덫, 성벽)은 손에 들면 설치 위치에 초록(가능)·빨강(불가) 홀로그램이 보입니다. 거리 제한 14 스터드는 서버와 클라이언트가 같습니다.
- 던지는 도구는 좌클릭을 누르고 있으면 예상 궤적과 떨어질 위치가 보입니다.
- 회복 중 Q로 취소할 수 있고, 맞아서 경직되면 끊깁니다.

## 이동

| 항목 | 값 |
|---|---|
| 걷기 / 달리기(Shift) | 18 / 24 |
| 활 당김·조준 중 | ×0.7 |
| 슬라이드 (C) | 땅에 있고 속도 10 이상일 때. 시작 속도 = max(현재, 걷기) × 1.65, 마찰로 감속(exp(−2.8·t)), 속도 10 미만이나 1.1초에 끝. 쿨다운 0.9초. 카메라 2.2 스터드 낮아짐 |

서버는 상황별 배율을 곱해 캐릭터의 `SpeedMult` 속성에 넣고, 클라이언트 이동 컨트롤러가 이를 적용합니다.

| 배율 | 값 |
|---|---|
| 방어구 | 철 −6%, 다이아 −12% (방어구가 남아 있을 때만) |
| 다이아몬드 단검 들고 있음 | ×1.08 |
| 볼라 | ×0.25 |
| 경직 | ×0.5 |
| 회복 시전 | ×0.45 |
| 헤드헌터 발사 직후 | ×0.6 |
| 뿔피리 | ×1.2 |
| 덫 속박 | 0 (못 움직임, 점프도 불가) |

넉백은 `ApplyImpulse`로 해당 클라이언트에 보내고, 봇은 서버가 직접 밀어냅니다.

## 부정행위 방지

- 모든 원격 인자를 `Net.IsFiniteNumber`, `Net.IsVector3`, `Net.IsString`으로 검사합니다(NaN, 무한대, 너무 긴 문자열 거부).
- 발사 위치 7 스터드, 근접 사거리 +1.75 스터드, 설치 거리 14 스터드 제한.
- 쿨다운, 장전 시간, 탄약, 들고 있는 슬롯을 서버가 따로 계산합니다.
- 로드아웃은 서버에서 다시 검증하고, 잠긴 아이템은 쓸 수 없습니다.
