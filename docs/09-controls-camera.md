# 09. 조작과 카메라

관련 코드: 클라이언트 `InputAndKeybindController.luau`, `CameraAndViewmodelController.luau`, `MovementController.luau`, `WeaponAndProjectileController.luau`, `CharacterPoses.luau`. 상수는 `GameConfig.Camera`, `GameConfig.Movement`.

## 키 배치

| 동작 | 키보드·마우스 | 게임패드 | 터치 |
|---|---|---|---|
| 발사 / 휘두르기 / 당기기 | 좌클릭 (누르고 있으면 당김·충전) | R2 | FIRE |
| 조준 / 막기 | 우클릭 (누르고 있는 동안) | L2 | AIM (누를 때마다 켜고 끔) |
| 핫바 선택 | 1~6 (숫자패드도 가능), 마우스 휠 | R1 / L1 (다음 / 이전) | NEXT |
| 로드아웃 빌더 (로비) / 프리셋 교체 (라운드 준비 5초) | B | 십자키 위 | - |
| 슬라이드 | C | B | SLIDE |
| 1인칭 / 3인칭 | V | Y | VIEW |
| 어깨 바꾸기 | X | - | - |
| 불화살 켜고 끄기 | R | - | - |
| 회복 취소 | Q | - | - |
| 차크람 잡기 | F | - | - |
| 달리기 | Shift (누르고 있는 동안) | L3 | - |
| 관전 대상 바꾸기 (죽은 뒤) | 좌클릭 다음 / 우클릭 이전 | R2 / L2 | - |

- 터치 버튼은 무장했을 때만 나타나고, 무장이 풀리면 사라집니다.
- 채팅창 같은 입력칸에 글을 쓰는 중에는 키보드 단축키가 동작하지 않습니다.
- 창 밖으로 포커스가 나가면 당기기·충전·달리기가 모두 취소됩니다.
- V, X, 휠은 전투 중(무장 상태)에만 동작합니다.

## 아이템별 입력

| 종류 | 좌클릭 | 우클릭 |
|---|---|---|
| 활 (나무 활, 헤드헌터) | 누르고 있으면 당기고, 놓으면 발사. 당김 비율이 12% 미만이면 쏘지 않고 취소 | 조준 (FOV 축소) |
| 석궁, 총 | 바로 발사, 장전 시간 뒤 다시 쏠 수 있음 | 조준 |
| 슬링, 투창 | 누르고 있으면 충전, 놓으면 던짐 | - |
| 투척 단검, 차크람, 볼라, 작살 | 바로 던짐 | - |
| 근접 | 휘두르기. 전투 도끼는 길게 눌렀다 놓으면 내려찍기 | 철검·카타나: 막기 |
| 방패 | 들기 | 들기 |
| 연막탄, 화염구, 회복 플라스크 | 누르고 있으면 예상 궤적·낙하 지점 표시, 놓으면 던짐 | - |
| 곰 덫, 나무 성벽 | 설치 위치에 초록(가능)/빨강(불가) 홀로그램, 누르면 설치. 성벽은 바라보는 방향으로 섬 | - |
| 뿔피리 | 불기 (쿨다운 20초) | - |
| 붕대, 사과, 황금 사과 | 누르면 먹기·감기 시작 (Q로 취소) | - |

핫바의 아이템별 안내 문구(`HotbarHint`)는 [reference/equipment.md](reference/equipment.md)에 있습니다.

## 카메라

전투 카메라는 서버가 무장시킨 동안(매치, 결투, 사격장)과 관전 중에 켜집니다. 그 밖에는 Roblox 기본 카메라가 돌아 로비 화면을 마우스로 누를 수 있습니다.

| 항목 | 내용 |
|---|---|
| 방식 | 스크립트 카메라. 마우스를 화면 중앙에 고정하고 좌우(yaw)·상하(pitch)를 직접 계산. 캐릭터 몸은 카메라 좌우 방향으로 돌아감 |
| 상하 한계 | ±80도 |
| 3인칭 (기본) | 오른쪽 어깨 (2.5, 1.5, 6.5), X로 왼쪽 (−2.5, 1.5, 6.5). 스프링으로 부드럽게 옮겨감. 조준하면 어깨 쪽으로 당겨짐(가로 0.7배, 높이 0.9배, 거리 0.55배) |
| 벽 충돌 | 캐릭터와 어깨 사이, 어깨와 카메라 사이에 벽이 있으면 카메라를 벽 앞으로 당김 |
| 1인칭 (V) | 카메라를 머리 위치에 두고 자기 몸을 숨김(`LocalTransparencyModifier = 1`). 화면 앞에 팔과 들고 있는 장비 복제본(뷰모델)을 그림 |
| 슬라이드 | 카메라가 2.2 스터드 내려감 |
| FOV | 설정값(70~120, 기본 70). 원거리 무기 조준 중에는 무기의 `ZoomFOVAds`로 스프링 이동 |
| 감도 | 설정값(0.1~3) × 줌 배율. 줌할수록 감도가 줄어 정밀 조준이 쉬움 |
| 반동·흔들림 | 발사 반동과 피격 흔들림을 스프링(`SpringPhysics`)으로 pitch/yaw에 더함 |
| 화면 흔들림 (View Bobbing) | 걸을 때 1인칭 카메라와 뷰모델이 위아래·좌우로 흔들림. 설정에서 끌 수 있음 |
| 시작 시점 | 설정의 START IN FIRST PERSON이 켜져 있으면 1인칭으로 시작 |

| 무기 | 조준 FOV |
|---|---|
| 나무 활 | 55 |
| 석궁 | 55 |
| 헤드헌터 | 40 (스코프 테두리) |
| 플린트락 | 60 |
| 블런더버스 | 62 |
| 머스킷 | 45 (스코프 테두리) |

## 이동

[04번 문서의 이동](04-combat.md#이동)에 수치가 있습니다. 클라이언트 쪽 동작은 다음과 같습니다.

- 걷기 18, Shift 달리기 24. 서버가 캐릭터의 `SpeedMult` 속성에 넣은 배율(방어구, 경직, 볼라 등)을 곱하고, 활을 당기거나 조준 중이면 0.7배를 더 곱합니다.
- **슬라이드(C)**: 땅에 있고 속도가 10 이상일 때만 됩니다. 시작 속도는 max(현재 속도, 걷기 속도) × 1.65이고, `exp(−2.8·t)`로 줄어들어 속도 10 미만이 되거나 1.1초가 지나면 끝납니다. 슬라이드 중에는 기본 이동 조작을 끄고 미끄러지는 방향으로 캐릭터를 직접 움직입니다. 다시 쓰려면 0.9초 기다려야 합니다.
- **넉백**: 서버가 `ApplyImpulse`로 보낸 충격을 캐릭터에 적용합니다.
- **속박(곰 덫)**: 움직임과 점프가 모두 막힙니다.

## 캐릭터 자세 (`CharacterPoses`)

Roblox 기본 애니메이션 위에 상체 자세를 코드로 덧씌웁니다. 매 프레임(PreSimulation) 애니메이션이 관절을 쓴 뒤, 복제되는 캐릭터 속성을 읽어 R15 관절마다 회전을 더합니다. 그래서 다른 사람 화면에서도 같은 자세로 보입니다.

| 속성 | 자세 |
|---|---|
| `Pitch` | 조준 각도에 따라 허리(Waist)와 목(Neck)이 위아래로 기울어짐 |
| `EquippedItem` | 활 들기, 총 들기, 근접 무기 대기 자세 |
| `DrawRatio` | 활 시위를 당기는 팔 |
| `SwingAt` | 휘두르기 궤적 |
| `Blocking` | 막기·방패 들기 |
| `HealingUntil` | 회복 동작 |
| `Sliding` | 슬라이드 중 몸 기울이기 |
| `StaggerUntil` | 경직 중 흔들림 |

애니메이션이 건드리지 않는 관절은 직전 프레임 값이 남기 때문에, 관절마다 기본 자세를 기억해 두고 거기에 회전을 다시 더해 누적되지 않게 합니다. POTG 재생의 복제 인형도 같은 속성으로 움직입니다.
