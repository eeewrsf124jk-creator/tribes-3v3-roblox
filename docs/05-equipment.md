# 05. 장비와 로드아웃

모든 수치는 [reference/equipment.md](reference/equipment.md)에 필드 하나도 빠짐없이 있습니다. 이 문서는 규칙과 분류를 설명합니다. 데이터 원본은 `src/ReplicatedStorage/Modules/Config/EquipmentDatabase.luau`, 검증은 `src/ReplicatedStorage/Modules/Shared/LoadoutBudgetValidator.luau`입니다.

## 로드아웃 규칙

| 규칙 | 값 |
|---|---|
| 포인트 예산 | 최대 12포인트. 남은 포인트는 이월되지 않음 |
| 슬롯 | 무기·도구·회복 합쳐 최대 6칸 (핫바 1~6) |
| 방어구 | 전용 칸 1개, 하나만 |
| 같은 아이템 | 두 번 넣을 수 없음 |
| 탄약 | 활에는 화살이나 불화살 1묶음 이상, 총에는 총알 1묶음 이상 필요 |
| 잠긴 아이템 | 해금하지 않은 아이템은 넣을 수 없음 |
| 저장 | 프리셋 5개. 라운드 시작 전 5초 동안 B로 바꿀 수 있음 |

예산을 넘거나 규칙에 어긋나면 로드아웃 빌더가 빨간 오류를 보여 주고 저장을 막습니다. 서버도 같은 검증 코드를 다시 돌립니다.

## 탄약 묶음

| 종류 | 1묶음 | 포인트 | 최대 |
|---|---|---|---|
| 화살 (Arrows) | 12발 | 1 | 3묶음 = 36발 |
| 불화살 (FireArrows) | 6발 | 2 | 2묶음 = 12발 |
| 총알 (Bullets) | 6발 | 1 | 2묶음 = 12발 |

활을 든 상태에서 R을 누르면 일반 화살과 불화살을 바꿉니다. 화살이 떨어지면 활은 쏠 수 없습니다. 슬링과 뿔피리는 횟수 제한이 없고(뿔피리는 쿨다운만 있음), 차크람은 한 개를 던지고 돌아오면 다시 씁니다.

## 얻는 방법

| 구분 | 아이템 | 얻는 법 |
|---|---|---|
| 기본 지급 | 위 표에서 아래 두 줄을 뺀 24종 | 처음부터 Lv1로 보유 |
| 샤드로 해금 | 나무 활 10, 플린트락 10, 석궁 20, 블런더버스 20, 헤드헌터 30, 머스킷 30 | 그 무기의 샤드를 모으면 자동 해금. 또는 399 / 599 / 799 로벅스로 즉시 해금 |
| 랭크 전용 | 건틀릿 Glory 300, 쌍손도끼 600, 카타나 1000, 사신의 낫 1600 | 랭크 점수(Glory)가 기준에 닿으면 해금 |

해금 뒤에는 샤드로 Lv10까지 강화합니다([06번 문서](06-progression-economy.md)).
