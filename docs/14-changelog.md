## 2026-10-24 · 전체 문서화와 명세 대조

**문서**

- `docs/` 신설: 설명 문서 14개와 원본 명세(`docs/spec/original-spec.md`, 모델 이름만 지움).
- `docs/reference/` 7개를 코드와 빌드된 플레이스에서 자동 생성하는 `tools/gendocs.luau` 추가. 장비 34종의 모든 필드, GameConfig 전체, 원격 34개와 사용 위치, 파일 62개의 공개 함수, 타입, 빌더가 만든 월드·프리팹·화면 트리를 담습니다.
- 원격 사용 위치를 찾을 때 `local remote = Net.Reliable("X")`처럼 변수에 담아 쓰는 경우도 추적하도록 생성기를 보강.

**테스트**

- `tests/world.luau` 추가: Lune 안에서 Studio 빌더 Step 1~5를 실제로 돌려 충돌 그룹, 런타임 폴더, 화면 11개, 모든 장비의 프리팹, 원거리 Attachment, 근접 `DmgPoint`, 로비 구역과 스폰, 맵 4종의 공통 장치를 검사.
- `tests/harness.luau`에 월드 모드 추가(`.rbxl`을 열어 그 안의 ModuleScript 실행, 엔진 기능 흉내).
- `tests/place.luau`에 "코드가 부르는 모든 원격 이름이 `Net`에 선언됐는지" 검사 추가.

**명세 대조로 채운 기능**

- 플린트락·블런더버스·머스킷의 공이(`HammerMotor`)가 쏠 때 앞으로 젖혔다가 장전 시간 동안 되돌아옴.
- 슬링을 충전하는 동안 머리 위에서 원을 그리며 돌리고, 충전할수록 빨라짐.
- 곰 덫이 밟히면 톱니가 0.09초 Tween으로 90도 닫힘(전에는 순간 이동).
- 나무 성벽이 설치될 때 0.25초 동안 땅에서 솟아오름.
- 로비 전광판이 상위 25명 대신 명세대로 1~50위를 보여 주고, 클라이언트가 자동 스크롤.
- 조준 각도 상태 동기화(`ReplicateCharacterState`)를 10Hz에서 명세의 20Hz로.
- 캐릭터 판정 파트에 `CanCollide = false`를 명시.

**바로잡은 것**

- 사용하지 않던 원격 `DuelAction` 삭제.
- 로비 GOLDEN DROP 버튼 가격을 결제 카탈로그에서 읽도록(10R$로 고정돼 있던 문구 → 9R$).
- 경제 서비스 머리 주석의 골든 드롭 가격 10 → 9 R$.
- 슬링 설명 "Never runs out of stones"(실제로 무제한)로 수정.
- 나무 성벽 핫바 안내의 `[R] Rotate` 삭제. 회전 기능은 없고 R은 불화살 전환이라 잘못된 안내였음. 바라보는 방향으로 선다는 안내로 교체.
- 붕대·사과 안내 `[LMB hold]` → `[LMB] ... [Q] Cancel`. 누르면 바로 시작하고 떼도 멈추지 않기 때문.
- 상자 몫 나누기 주석을 실제 동작(큰 몫부터 카드가 뒤집힘)에 맞춤.
